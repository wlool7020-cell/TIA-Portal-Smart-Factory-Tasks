# TIA Portal & Smart Factory PLC Automation Tasks

An open-source collection of modular PLC programming tasks, control logic blocks, and simulation examples built with **Siemens TIA Portal** for Smart Factory and Industry 4.0 applications.

## Overview
Open-source resources for industrial automation are often scarce or fragmented. This repository provides practical, well-structured PLC tasks designed to help automation engineers, researchers, and students understand, test, and reuse industrial control logic.

## Contents
- **Control Logic & Function Blocks:** Modular Ladder (LAD) and Structured Control Language (SCL) implementations.
- **Process Automation Tasks:** Sequential control, conveyor/sorting logic, and sensor-actuator integration.
- **Simulation Workflows:** Ready-to-test configurations for PLCSIM and virtual commissioning.

## How to Use
1. Clone or download this repository.
2. Open the project archive (`.zap` / `.ap`) or import the `.scl` source blocks into **Siemens TIA Portal**.
3. Run the logic using **S7-PLCSIM** to test and monitor tag states.
